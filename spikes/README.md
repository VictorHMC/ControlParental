# Pruebas técnicas aisladas

Crear `ipad/`, `android/` y `windows/` al generar cada prototipo con herramientas oficiales. Seguir los [protocolos](../docs/pruebas-tecnicas.md) y guardar informes anonimizados en `resultados/` utilizando su plantilla.

No confundir estos experimentos con código listo para producción. La prueba de iPad requiere Mac y equipo físico; Android administrado requiere un entorno de laboratorio apropiado. Todos los resultados iniciales están pendientes.
