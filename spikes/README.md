# Pruebas técnicas aisladas

El [laboratorio Windows](windows/README.md) ya contiene el primer prototipo. Crear `ipad/` y `android/` al disponer de sus herramientas. Seguir los [protocolos](../docs/pruebas-tecnicas.md) y guardar informes anonimizados en `resultados/` utilizando su plantilla.

No confundir estos experimentos con código listo para producción. La prueba de iPad requiere Mac y equipo físico; Android administrado requiere un entorno de laboratorio apropiado. Windows tiene pruebas de componentes aprobadas y bloqueo de plataforma pendiente.
